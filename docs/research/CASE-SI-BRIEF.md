# 系统集成项目管理工程师 · 案例分析出题规格（v2.9 调研）

> 用途：指导「案例分析（大题）」题库扩充。基于 2025 年三批真题、2024 第一批真题与历年考点归纳（来源见文末）。
> 结论：拿到本文档即可直接写题，无需再查资料。

## 一、真实考试结构

- 下午案例分析一般 **4 道大题**，每题 15~20 分，**每道大题 2~4 个小问**，小问 5~9 分。
- 答题方式：**问答题 + 计算题 + 找茬题（指出问题并改正）+ 补全流程/表格**。
- 评分：**按采分点给分**。计算题的标准结构是「公式代入 → 数值 → 结论判断」三段式，缺结论通常扣分。

## 二、考点频率表（近 5-8 年）

| 考点 | 出题形态 | 频率 |
|---|---|---|
| 挣值分析（PV/EV/AC/CV/SV/CPI/SPI/EAC/ETC） | 计算 + 绩效判断 | 极高（几乎必考） |
| 三点估算 / 期望工期 / 正态分布概率 | 计算 | 高 |
| 关键路径 / 总时差 / 自由时差 | 计算 + 画图 | 极高 |
| 进度压缩（赶工成本斜率、快速跟进风险） | 计算 + 方案选择 | 高 |
| 变更管理找茬（无流程、未评估影响、口头变更） | 找茬 + 补流程 | 极高 |
| 范围失控（镀金、范围蔓延、缺 WBS） | 找茬 | 高 |
| 配置管理（三库、基线、配置审计） | 找茬 + 流程 | 高 |
| 质量管理（QA/QC 混淆、因果图、帕累托） | 找茬 + 工具应用 | 高 |
| 风险（EMV 决策树、应对策略匹配、储备区分） | 计算 + 匹配 | 中高 |
| 合同索赔（工期/费用索赔计算、合同类型选择） | 计算 + 找茬 | 中高 |
| 采购与招投标（流程时限、评标找茬） | 找茬 + 法条时限 | 中 |
| 沟通与干系人（渠道数计算、矩阵应用、识别遗漏） | 计算 + 找茬 | 高 |
| 团队与冲突（冲突处理方法、激励理论） | 场景问答 | 中 |
| 启动与章程（找茬：越权、缺章程开工） | 找茬 | 中 |
| 收尾（行政收尾/合同收尾、经验教训） | 流程问答 | 中 |
| 信息安全 / 新兴技术（等保、云、大数据评估） | 方案分析 | 中低 |

## 三、案例选题规格（本章新题批次 si-case2-01~20）

每条 = 标题 / 章节（白名单原名）/ 背景 / 小问设计 / 答案要点 / 难度。计算题数值已验算自洽。

1. **挣值综合计算与完工预测**｜进度控制与进度成本｜BAC=240 万、4 月末 PV=120/EV=100/AC=110 → CV=−10、SV=−20、CPI≈0.91、SPI≈0.83；典型偏差 EAC=BAC/CPI=264 万、ETC=154 万；纠偏措施。难度 4
2. **三点估算 + 关键路径 + 延误影响**｜进度网络图与关键路径法｜A(2,4,6)B(1,2,3)C(3,6,9)D(2,5,8)E(1,4,7)F=1；关键路径 A-C-E-F=15；D 路径总时差 3，延误 4 周 → 工期延 1 周且关键路径转移。难度 4
3. **赶工成本斜率决策**｜进度压缩｜压 A(2万/周,限1) + C(3万/周,限2) 共 2 周最少花 5 万；不选 E(5万/周)；快速跟进风险。难度 4
4. **网络图逻辑找茬**｜活动排序与网络图绘制｜紧前关系表含循环依赖与冗余依赖；修正后说明关键路径确定方法。难度 3
5. **资源平滑 vs 资源平衡**｜资源平衡与资源平滑｜6 人需求 4 人供给；用非关键活动总时差错峰（平滑，工期不变）；平衡则改工期。难度 3
6. **变更管理找茬**｜项目整体管理｜口头变更直接实施、无影响评估、无 CCB、已实施未更新基准；补全七步流程。难度 3
7. **配置审计与基线**｜项目配置管理｜开发库直接改基线、无变更申请、审计缺功能配置审计；给出三库流转与审计流程。难度 3
8. **QA/QC 职责混淆找茬**｜项目质量管理｜把测试当质量保证、无质量保证计划、验收标准未定；补 QA/QC 分工。难度 3
9. **因果图 + 帕累托定位主因**｜质量工具与质量成本｜给 6 类缺陷计数（合计 100：接口 52、配置 20、数据 12、界面 8、文档 5、其他 3），按 80/20 找主要缺陷并画（描述）因果图分支。难度 3
10. **质量成本归因**｜质量工具与质量成本｜把给定支出归类预防/评估/内部失败/外部失败并说明「预防 1 元省失败 10 元」。难度 3
11. **合同索赔计算**｜项目合同管理｜可索赔工期 = 非乙方责任延误且在关键路径上；费用索赔只含直接损失不含利润（除非合同约定）；给数据算索赔工期 2 周、费用 8 万。难度 4
12. **评标流程找茬**｜项目采购管理｜开标前拆封、评标委员会构成不合规、以最低价唯一标准；补合规流程。难度 3
13. **EMV 决策树选方案**｜风险分析与评价｜A 方案 0.7×100+0.3×(−20)=64，B 方案 0.7×50+0.3×10=38 → 选 A；说明期望值含义。难度 4
14. **风险应对策略匹配**｜风险应对与储备｜给 6 个场景匹配规避/转移/减轻/接受并说理由。难度 3
15. **储备使用场景判断**｜风险应对与储备｜已识别风险用应急储备（进成本基准）、未知未知用管理储备（走管理层审批）。难度 3
16. **干系人矩阵与沟通**｜项目干系人管理｜权力高利益低→令其满意（定期报告）；识别遗漏关键干系人导致返工的找茬。难度 3
17. **沟通渠道计算与计划**｜项目沟通管理｜团队从 6 人扩到 10 人：15→45 条渠道；找茬：全员日报信息过载，应分层沟通。难度 3
18. **冲突处理与团队建设**｜团队发展与冲突管理｜两名骨干技术路线冲突；合作/解决问题优先，强迫是下策；塔克曼阶段判断。难度 3
19. **启动过程找茬**｜启动过程组｜未拿到章程即开工、项目经理口头任命、可行性未做；补正确启动顺序。难度 3
20. **收尾流程**｜收尾过程组｜行政收尾与合同收尾内容、经验教训归档、团队解散与客户正式验收。难度 3

## 四、写题规范

- 计算题数值必须**先算后写、自洽**（本文件内已验算）；金额单位统一「万元」、时间统一「周」。
- 术语与《系统集成项目管理工程师教程》第 3 版一致（挣值英文缩写、五类标准、三库、七步变更等）。
- 每小问独立成一条题目记录（type=case），共享 caseId 与 caseStudy 背景；解析 = 该小问参考答案（采分点式）；AI 深度解析 160~280 字，开头用「本小问考查…」，避免「答案A」式开头。
- 来源写「改编自……真题」或「自编（依据教程第 3 版 × 章）」，不逐字复制任何培训机构的原题文本。
