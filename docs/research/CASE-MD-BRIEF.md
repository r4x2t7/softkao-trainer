# 多媒体应用设计师 · 案例分析出题规格（v2.9 调研）

> 用途：指导「案例分析（大题）」题库扩充。基于历年下午题（应用技术）考点归纳与容量计算类真题模板。
> 结论：拿到本文档即可直接写题，无需再查资料。

## 一、真实考试结构

- 下午「多媒体应用技术」（案例分析）一般 **4~5 道大题**，每题 15 分上下，**每题 2~4 个小问**。
- 题型：**计算题（容量/码率/压缩比）+ 方案分析题（选型/流程/找茬）+ 补全题（流程、参数表）**。
- 计算题评分同样是「公式 → 代入 → 结果（带单位）」三段式；单位错或不带单位要扣分。

## 三、案例选题规格（md-case2-01~15，数值已验算）

1. **图像容量与压缩比**｜分辨率与图像容量｜1600×1200×24bit 未压缩单张 5,760,000B≈5.5MB，100 张≈549MB，压进 120MB 需压缩比≈4.6:1（工程取 5:1）；JPEG 有损取舍。难度 3
2. **音频容量与格式选择**｜音频参数与计算｜CD 质量 44.1kHz/16bit/双声道/5 分钟 = 44100×16×2×300÷8≈50.5MB；MP3 128kbps 同长≈4.6MB；压缩比≈11:1。难度 3
3. **视频码率与存储**｜视频参数与计算｜1080p25 YUV4:2:0 未压缩 77.76MB/s≈622Mbps，1 小时≈273GB；H.264 4Mbps 1 小时≈1.8GB；压缩比≈152:1。难度 4
4. **JPEG 管线分析**｜JPEG与DCT｜FDCT→量化（有损在此步）→DC 差分→RLE→Huffman；8×8 分块的意义；质量因子与体积关系。难度 3
5. **GOP 与帧结构**｜帧与编码｜IBBP 结构、GOP=12 时一个 GOP 含 1 个 I 帧、3 个 P 帧、8 个 B 帧（I:P:B=1:3:8）；I 多则码率高、随机访问快；直播短 GOP 降延迟但码率升。难度 4
6. **冗余类型归类**｜冗余与压缩比｜空间/时间/统计/视觉冗余各举一例并配对编码手段。难度 3
7. **直播平台部署与带宽**｜流媒体技术｜1000 人并发 2Mbps → 出口≥2Gbps；RTMP 推流 + HTTP-FLV/HLS 分发对比（延迟与兼容性）；CDN 缓解源站。难度 4
8. **付费内容保护方案**｜传输与安全｜分级 DRM + 许可证 + 设备绑定 + 水印溯源 + Referer/Token 防盗链；DRM 局限（录屏）。难度 3
9. **音频降噪与后期流程**｜音频格式与编辑｜录音棚环境噪声处理：采样降噪/滤波降噪/噪声门限的适用条件；导出格式选择。难度 3
10. **开发流程找茬**｜多媒体项目实施｜未定设计规格就采集素材导致返工；改成「需求→设计→素材→集成→测试→发布→运维」并说明螺旋/原型适用场景。难度 3
11. **交互体验改进**｜交互设计｜加载无反馈、层级过深、错误提示技术化三条找茬 + 改法（进度反馈、扁平导航、人话提示）。难度 3
12. **跨媒体色彩一致性**｜色彩与色彩管理｜屏幕 RGB 预览 vs 印刷 CMYK 色差问题；色彩空间转换与色域映射意图。难度 3
13. **素材版权合规**｜标准与版权｜字体商用授权、图库许可范围、背景音乐授权链条；侵权后果与合规清单。难度 3
14. **图像库检索**｜多媒体数据库｜基于内容检索（颜色/纹理/形状特征）与关键词标注结合的方案分析。难度 3
15. **矢量与位图选型**｜数字图形与图像基础｜Logo 用矢量（无限缩放、体积小）、照片用位图；导出规格与透明通道。难度 3

## 四、写题规范

- 公式一律在解析里完整写出（如「单张容量 = 宽 × 高 × 位深 ÷ 8」），结果**带单位**（MB/MB/s/Mbps）。
- 1MB = 1024×1024 B 的口径与教程一致；码率换算 1 byte = 8 bit。
- 术语与教程一致（YUV4:2:0、GOP、CBIR、色域映射意图等）。
- 每小问独立成题记录（type=case、共享 caseId/caseStudy），解析 = 参考答案，AI 深度解析 160~280 字、开头「本小问考查…」。
- 来源写「改编自……真题」或「自编（依据教程 × 章）」，不逐字复制培训机构文本。
